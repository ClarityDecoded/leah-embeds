# CLAUDE.md — instructions for Claude Code working in this repo

This repo (`leah-embeds`) is the **content host** for the Framer embeds on Leah
Lamb's site (School for Sacred Storytelling). Each Framer page holds one small
loader snippet that pulls its content from here and renders it. Editing happens
here, not in Framer.

Live site: https://claritydecoded.github.io/leah-embeds/ (served by GitHub Pages
from `main`). The `/` control panel lists every page and block.

## The golden rules

1. **Edit `source/<slug>.html`. NEVER edit anything under `embeds/`** — that whole
   folder is generated by `build.py` and is overwritten on every build.
2. **Keep `STATUS.md` current.** It's the project status file so the next session
   knows what's going on. After any change that ships, update its "Current state"
   / "Known issues" and add a dated entry to the top of its Change log. Read it
   first at the start of a session to get oriented.

## The 4 pages (slugs)

`deep-story` · `luminaries` · `soul-stories` · `soul-story-council`
→ source files: `source/deep-story.html`, etc.

## How to make and ship a change

1. Edit the relevant `source/<slug>.html`. Each page is split into **blocks**:
   ```html
   <!-- ===== BLOCK 3 — the practice ===== -->
      ... this block's self-contained HTML + CSS ...
   <!-- ===== end block 3 ===== -->
   ```
   Change text, swap an image (`https://framerusercontent.com/...` URLs), adjust
   CSS, or add/remove/reorder a whole block by editing between these markers.
2. Rebuild: `python3 build.py` (regenerates `embeds/`, stamps a new version `v`).
3. Commit + push. GitHub Pages redeploys automatically (~1 min); Framer shows the
   change on next page load. **Do not touch Framer.**

Requirements: `git` + `python3` only. No npm/build tooling.

## Architecture (why it's built this way)

- Each block renders in its **own iframe** (`build.py` wraps it as a standalone
  doc). The original blocks use global, unscoped CSS (`body`, `h1`, `.wrap`), so
  they MUST stay isolated — never merge blocks into one document.
- `loader.js` (referenced by Framer) fetches a page's `manifest.json`, renders one
  auto-resizing iframe per block, and reports total height to Framer.
- Height is measured from `<body>` (not `documentElement`, which is viewport-clamped
  and caused gaps). Width is set explicitly per iframe (a `width:100%` iframe can
  compute a 0-width viewport and collapse `vw`-sized blocks).

## Global (cross-page) behavior — change here, not per block

- **`loader.js`** — how embeds load, size, and report height to Framer. It also
  neutralizes Framer's `display:flex` embed wrapper and re-asserts height for ~30s
  (tall/slow pages). If embeds render blank or with big gaps, look here first.
- **`build.py` → `WRAPPER` `<style>`** — the per-block `<head>` styles, including
  the **900px cap** on full-width feature images (`img` + Luminaries `.hero-img` /
  `.break-img`), applied with `!important` so block styles don't override it.

## Verifying

`index.html` (the control panel) and each `embeds/<slug>/NN.html` can be opened
directly to preview a block. Test a real embed by loading the live Framer page
and letting it settle a few seconds (CDN images + height sync).
